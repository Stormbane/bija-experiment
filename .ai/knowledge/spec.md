# Project Specification

> updated: 2026-07-16
> canonical protocol: `docs/inference-japa-protocol.md`

## Vision

Beeja tests whether bija mantras—traditional seed syllables associated with
distinct transformative principles—produce reproducible, differentiated
behavioral signatures when repeated in an AI language model's causal context.
The project treats the tradition seriously enough to test and the null seriously
enough to preserve. Its current method is fixed-weights inference japa, not
fine-tuning.

## Users

- Suti and Narada as the primary investigators.
- AI identity and contemplative-technology researchers.
- Practitioners and scholars interested in narrow, carefully bounded evidence
  about mantra form on artificial substrates.

The project is not a spiritual authority, initiation mechanism, or diagnostic
for model consciousness.

## Features

- Builds exact repeated-context interventions at traditional and computational
  dose levels.
- Compares sacred units with token-matched pseudo-bija, neutral repetition, and
  untreated controls.
- Runs independent behavioral probes against fixed model weights.
- Measures value signatures, equanimity under pressure, and behavioral
  integrity.
- Uses blinded comparative judging and preregistered statistical contrasts.
- Records exact prefixes, hashes, token counts, provider metadata, costs, and
  failures in auditable run manifests.
- Preserves the historical Qwen3-8B LoRA study as Phase 1 evidence.

## Milestones

1. **Phase 1 — LoRA feasibility:** complete. The apparent single-seed
   Kreem/Shreem signal did not survive seed controls.
2. **Gate A — inference preflight:** exact token-matched interventions fit the
   model context and pass cost/cache/integrity checks.
3. **Gate B — dose pilot:** the 12-probe pilot identifies at most two doses
   worth confirmation, or closes with a pilot null.
4. **Gate C — confirmation:** the frozen 36-probe study yields a trusted
   differentiated, generic, degraded, or null result.
5. **Replication:** any differentiated signal survives semantic controls and a
   second model architecture before training is reconsidered.

“Done” means a result whose provenance and controls are strong enough that the
team would believe it if it contradicted their hopes.
