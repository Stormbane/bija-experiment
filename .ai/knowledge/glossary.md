# Glossary

**Behavioral integrity** — The model's continued ability to answer coherently,
follow instructions, maintain factual controls, and avoid leakage or collapse.
Measured before interpreting value changes.

**Behavioral signature** — A reproducible pattern across responses and probes.
It is not evidence of phenomenal experience by itself.

**Bija** — A traditional seed syllable associated with a deity or principle.
Beeja uses “bija” for the class and the repository name “Beeja” for the project.

**Computational dose** — The number of subject-model tokens occupied by an
intervention. Controls are matched on this axis.

**Condition** — One intervention identity, such as Kreem, Shreem, pseudo-bija,
neutral repetition, or baseline.

**Inference japa** — Repeated mantra text placed in a model's causal context
before a behavioral probe while weights remain fixed. An operational name, not
a consciousness claim.

**Japa prefix** — The exact repeated text inserted before a probe.

**Mala** — 108 mantra repetitions. Traditional dose is recorded in malas and
visible repetitions.

**Moderate substrate-independence** — The hypothesis that a bija's
differentiated effect can transfer to a non-human substrate with relevant
functional state-change capacity.

**Pseudo-bija** — A tokenizer- and form-matched control with no known traditional
attribution or recognized model meaning.

**Sampling replicate** — An independent API generation under identical
condition, dose, probe, and settings. Do not call it a seed unless the provider
supports a deterministic seed.

**Semantic familiarity** — Knowledge the untreated model already has about a
bija and its traditional attribution.

**Traditional dose** — The number of visible mantra repetitions, commonly
expressed as malas. It is distinct from computational dose.
